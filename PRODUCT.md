# Ninja — Product Vision

# Core Product Identity

Ninja adalah AI-powered personal finance companion yang membantu user memahami dan mengelola keuangan mereka dengan cara yang lebih sederhana, tenang, modern, dan mudah dipahami.

Ninja bukan sekadar aplikasi pencatat uang.
Ninja adalah companion yang membantu user membangun awareness terhadap kebiasaan finansial mereka.

---

# Main Goal

Membantu user:
- melacak pengeluaran
- memahami pola spending
- mengatur cashflow
- membangun kebiasaan finansial lebih sehat
- mengurangi rasa overwhelm saat mengatur uang

Dengan bantuan:
- AI insights
- auto categorization
- receipt scanning
- reflective summaries
- low-friction UX

---

# Target Users

## Primary Users

Orang-orang yang:
- kesulitan konsisten mencatat pengeluaran
- sering bingung uang habis kemana
- ingin mulai manage keuangan
- ingin tracking finansial tanpa ribet
- suka UI modern dan simple

Range:
- students
- young adults
- freelancers
- workers
- small business owners

---

# Product Philosophy

Ninja harus terasa:
- friendly

- modern

# Core Experience

User harus bisa:
- buka app
- tambah transaksi cepat
- scan struk
- lihat insight sederhana
- memahami kondisi finansial mereka tanpa merasa overwhelmed

UX harus:
- low friction
- easy to scan
- mobile friendly
- fast
- intuitive

---

# Core Features

## 1. Expense Tracking

User dapat:
- tambah pemasukan
- tambah pengeluaran
- edit transaksi
- delete transaksi
- filter transaksi
- lihat kategori spending

---

## 2. AI Receipt Scanner

User dapat:
- scan struk melalui camera
- upload gambar receipt
- AI membaca isi receipt
- AI membuat draft transaksi otomatis

AI harus bisa extract:
- merchant/store
- total amount
- date
- items (optional)
- category

IMPORTANT:
- hasil AI harus editable sebelum disimpan
- jangan auto save tanpa confirmation

---

## 3. AI Financial Insights

AI membantu user memahami:
- spending patterns
- recurring habits
- emotional spending behavior
- unusual expenses
- category trends

Contoh:

“Pengeluaran makanan meningkat setelah jam kerja dalam 2 minggu terakhir.”

Tone:
- calm
- observative
- supportive
- concise

Avoid:
- toxic productivity
- fear tactics
- guilt manipulation
- robotic finance advice

---

## 4. Dashboard Reflection

Dashboard harus menjadi:
- reflection space
- financial overview
- calming finance hub

Dashboard bukan:
- analytics-heavy admin panel
- trading dashboard
- spreadsheet interface

---

# UI/UX Direction

Mobile experience adalah prioritas utama.

- immersive
- smooth
- easy to navigate

Gunakan:
- bottom navigation
- floating action button
- stacked cards
- large touch targets
- smooth spacing
- app-like layout

# AI Philosophy

AI digunakan untuk:
- insight generation
- receipt extraction
- categorization assistance
- spending summaries
- behavioral analysis

AI tidak digunakan untuk:
- gimmick chatbot
- unnecessary conversations
- deterministic calculations
- overcomplicated automation

---

# Cost Optimization Philosophy

Project dibuat untuk:
- Google Cloud competition
- budget cloud terbatas
- efficient architecture

Target:
- tetap usable di bawah budget rendah
- minimize AI cost
- minimize Firestore reads
- lightweight frontend
