# Ninja — Design System

# Design Direction

Visual direction Ninja:
- minimal
- calm
- modern
- breathable
- soft futuristic
- mobile-first
- premium simplicity

Avoid:
- crypto dashboard vibes
- neon overload
- cyberpunk UI
- crowded analytics layout
- gaming interface

# Color Rules

Use:
- dark neutral backgrounds
- subtle teal accents
- soft contrast
- minimal glow
- readable typography

Avoid:
- oversaturated cyan
- neon gradients
- aggressive contrast
- too many accent colors

Accent colors should be used sparingly.

- generous line height
- clean hierarchy
- airy spacing

- compressed text
- too many font sizes
- excessive bold usage

# Shadows

Use soft shadows only.

Avoid:
- harsh black shadows
- strong glow shadows
- neon lighting

Preferred:
- layered soft shadows
- subtle depth
- atmospheric surfaces

---

# Glassmorphism Rules

Glass effect should be:
- subtle
- soft
- elegant
- low opacity

Preferred:
- backdrop blur
- low transparency
- soft borders
- layered depth

Avoid:
- extreme blur
- rainbow gradients
- crypto glow
- heavy transparency

---

# Layout Philosophy

Layout should feel:
- spacious
- relaxing
- immersive
- easy to scan
- uncluttered

Avoid:
- dense dashboards
- tiny cards
- crowded grids
- analytics-heavy layouts

---

# Mobile Layout Rules

Mobile should feel like:
- native app
- touch-friendly
- immersive
- smooth

Use:
- bottom navigation
- floating action button
- sticky mobile nav
- stacked layout
- swipe-friendly spacing

---

# Desktop Layout Rules

Desktop should feel:
- structured
- calm
- modern
- organized

Use:
- clear hierarchy
- larger spacing
- balanced whitespace
- modular sections

---

# Component Rules

## Cards

Cards should:
- have enough padding
- feel elevated
- use subtle borders
- avoid visual noise

## Buttons

Buttons should:
- be simple
- readable
- high contrast
- easy to tap

Avoid:
- oversized glow
- too many gradients
- excessive animation

---

# Dashboard Structure

## Main Priority

1. AI Reflection
2. Spending Overview
3. Quick Actions
4. Recent Transactions
5. Savings Progress

Charts should be secondary.

---

# Animation Rules

Animations should feel:
- smooth
- calm
- premium
- soft

Use:
- fade transitions
- soft scaling
- gentle motion
- subtle hover states

Avoid:
- aggressive bounce
- flashy effects
- chaotic movement
- gaming animation

---

# Responsive Philosophy

Mobile is the main experience.

Desktop adapts from mobile logic.

Never:
- force desktop layout into mobile
- shrink complex dashboard into phone screen
- overload mobile screen with analytics

---

# Final Visual Feeling

Ninja should feel like:

“A calm modern finance app with soft futuristic visuals and simple AI-powered experiences.”
